# Security

Thank you for helping keep Byparr Manager and its users safe.

- **Do not** post passwords, API keys, cookies, access tokens, private tracker URLs, or unredacted diagnostic logs in public issues.
- For a suspected vulnerability, do not open a public issue with exploit details or sensitive information.
- At present, this is a small community project without a dedicated private security response team. Please use GitHub's private vulnerability reporting feature for this repository if it is enabled. If it is not available, do not publish sensitive details; first open a non-sensitive issue asking for a private contact route.
- Do not assume a report is being actively monitored or that a fix can be delivered by a particular date.

Please include only the minimum information needed to identify the affected release and impact.
